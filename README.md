# 🐍 Classic Snake Game

A classic implementation of the retro Snake game built with clean and efficient code. Guide the snake, eat the food, grow longer, and try to beat your highest score without hitting the walls or yourself!

---

## 🚀 Features

* **Classic Gameplay:** Smooth controls and traditional snake mechanics.
* **Score Tracking:** Real-time score counter to keep track of your performance.
* **Responsive Controls:** Intuitive keyboard direction handling.
* **Lightweight & Fast:** Built with pure code with minimal dependencies.

---

## 🕹️ How to Play

1. Use the **Arrow Keys** (or `W`, `A`, `S`, `D`) to control the direction of the snake.
2. Eat the food appearing on the screen to grow longer and increase your score.
3. Avoid hitting the boundaries of the game board or running into the snake's own tail.
